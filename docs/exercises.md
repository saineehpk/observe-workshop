# แบบฝึกหัด

มี 3 ข้อ ทุกข้อทำ 3 ขั้นเหมือนกัน (หลัง `make start`):

1. **รัน `make exN`** ระบบจำลองเคสของข้อนั้นให้เกิด log, metric และ trace จริง แล้วพิมพ์ ticket ออกมา
2. **อ่าน ticket** แบบที่ Support ส่งมา: ชื่อเว็บ · username · เวลาโดยประมาณ · อาการ
3. **วาง prompt ใน Claude** พิมพ์ `claude` ในโฟลเดอร์ repo แล้วก๊อป prompt ที่ `make exN` พิมพ์ให้ไปวาง

เช็คคำตอบของ Claude ด้วยคำถาม "log บรรทัดไหนบอกแบบนั้น" ทุกคำตอบต้องติดป้าย **Observed** / **Inferred** / **Unknown**
Claude หาเคสไม่เจอ ให้รัน `make hint` จะได้ trace_id ของข้อล่าสุด รันซ้ำกี่รอบก็ได้ ทุกรอบเริ่มจากสถานะเดียวกัน

ระบบมี 3 เว็บ = 3 namespace (`web-alpha`, `web-bravo`, `web-charlie`) username ขึ้นต้นด้วยชื่อเว็บ เช่น `bravo0006`

---

## ข้อ 1 · "เกิดข้อผิดพลาด" ตอนย้ายกระเป๋า

```bash
make ex1
```

```text
┌─ ticket ─────────────────────────────────────────────
│ เว็บ:     web-alpha
│ ผู้เล่น:   alpha0004
│ เวลา:     ประมาณ 14:20
│ อาการ:    ย้ายยอด 50 จากกระเป๋าเข้าเครดิต ครั้งที่สองขึ้น "เกิดข้อผิดพลาด กรุณาลองใหม่"
└──────────────────────────────────────────────────────
```

วาง prompt ที่พิมพ์ออกมาใน Claude · คุยต่อ: record ที่เจอบอกตรงกับยอดเงินจริงไหม

## ข้อ 2 · เช็คอินรับได้สองครั้ง

```bash
make ex2
```

```text
┌─ ticket ─────────────────────────────────────────────
│ เว็บ:     web-charlie
│ ผู้เล่น:   charlie0005
│ เวลา:     ประมาณ 14:45
│ อาการ:    (ทีมบัญชีแจ้ง) ผู้เล่นรับรางวัลเช็คอินได้ 2 ครั้งในวันเดียว
└──────────────────────────────────────────────────────
```

วาง prompt ที่พิมพ์ออกมาใน Claude · คุยต่อ: ทำไมเกิดแค่บางเว็บ และ metric ตอนนี้เห็นเคสนี้ไหม

## ข้อ 3 · ถอนแล้ว "กำลังดำเนินการ"

```bash
make ex3
```

```text
┌─ ticket ─────────────────────────────────────────────
│ เว็บ:     web-bravo
│ ผู้เล่น:   bravo0006
│ เวลา:     ประมาณ 15:10
│ อาการ:    ถอน 200 แล้วขึ้น "รายการกำลังดำเนินการ กรุณาตรวจสอบประวัติการถอน" ไม่แน่ใจว่าเงินถูกตัดหรือยัง
└──────────────────────────────────────────────────────
```

วาง prompt ที่พิมพ์ออกมาใน Claude · คุยต่อ: api กับ worker บอกต่างกันยังไง ใครเป็นแหล่งความจริงเรื่องเงิน (เปิด trace ใน Tempo ประกอบ)

## prompt ที่ `make exN` พิมพ์ให้ (หน้าตาแบบนี้)

```text
ลูกค้าเว็บ <เว็บ> (namespace <เว็บ>) username <username> แจ้งว่า <อาการ> ประมาณ <HH:MM>
ใช้ grafana-local หา trace_id ของเคสนี้จาก Loki แล้วดึง log ทุกบรรทัดของ trace นั้น
เรียงตามเวลา วาด flow ทีละ stage ข้าม service แล้วตอบ 4 ข้อ:
พังขั้นไหน / เพราะอะไร / เงินขยับไหม / ผู้เล่นได้คำตอบอะไร
ติดป้าย Observed / Inferred / Unknown ทุกข้อ และแสดง query ที่ใช้
```
